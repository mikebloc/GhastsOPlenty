> Plugin that replaces every mob as a Ghast.

- Consider [donating!](https://ko-fi.com/cutzuu)

## Contributing
Check [here](https://github.com/cutzuu/.github/blob/main/documentation/contributing.md) for details.


### All mob spawns are replaced as Ghasts except:
- Non-mobs
- Villagers
- Some lingering mobs due to chance.(May revisit one day)

### Features
- Ghast explosions are replaced with custom explosion size.
- Ghast deaths by you, they drop 1 Bread / 1 Feather.
- Night time is chaotic. (This may be toned down in the future)

### You can now configure/reload aspects such as:
- Explosive Power
- Ghasts Attach Each Other
- Squid Replacement Spam
- Togglable Player Damage
